# Currency Converter

A simple app that converts an amount from one currency to another

## Features
-Enter an amount and choose the "from" and "to" currencies
-Get the converted value instantly
-Supports multiple currencies

## Tech Stack
HTML,CSS,JAVASCRIPT

## Project files
-`index.html`:the main html file
-`style.css`: css for the project
-`app.js`: the main js file
-`code.js`: contains currencies and their code
